# Changelog

## 0.7.1
- Added compatibility definitions for `[mouseover]` and `[health:percent-with-absorbs]`, based on user scan results.
- Absorb-aware health falls back to regular health percentage when the client does not expose an absorb API.

## 0.7.0
- Expanded the compatibility tag set.
- Added native ElvUI options integration and related compatibility work.
- Added README notes for WotLK limitations and unknown-tag scanning.

## 0.6.1
- Follow-up fixes to plugin registration and delayed tag metadata handling.
- Intended to avoid disrupting the ElvUI options tree on the WotLK backport.
